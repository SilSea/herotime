# เผ่า (Faction) — แนวการเล่นและแนวทางสมดุล

เอกสารนี้ใช้ตอน**ทำการ์ด**และ**ปรับสมดุล** ทุกการ์ดควรตอบได้ว่า "ช่วยแผนของเผ่าตัวเองตรงไหน"
ชื่อ trigger / action / keyword ในเอกสารตรงกับใน Card wizard และ Admin (ดู `ADMIN_GUIDE.md` ข้อ 6)

> สถานะ: แนวของ Beast, Kaiju, Mecha ผู้ใช้กำหนดเอง · Rider, Sentai มาจากระบบที่มีในเกม · Human, Shonen ตกลงตามข้อเสนอ (2026-10-08)

## 1. ภาพรวม

| เผ่า | แผนหลัก (ชนะด้วยอะไร) | กลไกหลัก | แรงช่วง | จุดแข็ง | จุดอ่อน |
|---|---|---|---|---|---|
| **Beast** | ลงสนามเยอะ ตัวที่ลงมาได้พลังเพิ่ม | Deploy, เมื่อเรียกยูนิตอื่นเข้าสนาม, Summon | ต้น–กลาง | บอร์ดเต็มเร็ว โตแบบกว้าง | ตัวเดี่ยวเล็ก แพ้ทำดาเมจหมู่ / ทำลายหลายตัว |
| **Kaiju** | ตายแล้วกลับมาแรงกว่าเดิม | Last Stand, Kyodaika, Revive, Avenge | กลาง–ปลาย | ทนทาน ตายยาก ได้เปรียบสู้ยาว | ต้นเกมอ่อน, แพ้ Lethal / ทำลายตรงๆ |
| **Mecha** | รวมร่างเป็นยูนิตใหญ่ที่อัปเกรดต่อได้ | Gattai, Gattai core, Super Gattai, Giant Robo | ปลาย | ร่างสุดท้ายแรงที่สุดในเกม | ต้องเรียงบอร์ด ต้องเก็บชิ้นครบ ช่วงรอแรงน้อย |
| **Rider** | ปั้นตัวเดียวให้โตสุด | Henshin, Final Form, Rider Gauge, Gear, Rider Kick | กลาง–ปลาย | ตัวเดียวแรงมาก ใช้ Gear คุ้ม | ตัวหลักตายเร็ว = แผนพัง, แพ้ Lethal / Guard หลายชั้น |
| **Sentai** | ทีมหลายสีเสริมกัน แล้วเรียกหุ่นยักษ์ | สี Sentai, Team-Up, Roll Call, Mecha Gauge, Giant Robo | กลาง | บัฟทั้งทีม หุ่นยักษ์ช่วยพลิกเกม | ต้องเก็บสีครบ ช่องบอร์ดตึง |
| **Human** | เศรษฐกิจ: มีของมากกว่าคนอื่น | ได้ Energy, บัฟร้าน, ได้การ์ด/Gear, Discover, ขายแล้วได้ของ | ต้น (เก็บ) → ปลาย (ใช้) | ยืดหยุ่น ผสมเผ่าอื่นได้ดีที่สุด | พลังสู้ตัวเองต่ำ, ถ้าไม่ไปต่อจะแพ้กลางเกม |
| **Shonen** | ยิ่งโดนยิ่งแกร่ง ท่าไม้ตายครั้งเดียว | เมื่อโดนดาเมจแล้วยังรอด, Avenge, Rapid, Rider Kick, limit ครั้งเดียว | กลาง–ปลาย | พลิกเกมในการสู้ยาว, โตถาวรจากการสู้ | ถ้าตายในทีเดียว (Lethal, ดาเมจสูง) ไม่ได้อะไรเลย |

**หลักแบ่งบทบาท** (ไม่ให้เผ่าซ้ำกัน)
- *โตแบบกว้าง* = Beast · *โตแบบสูง (ตัวเดียว)* = Rider · *โตจากการสู้* = Shonen · *โตจากความตาย* = Kaiju · *โตจากรวมร่าง* = Mecha · *โตทั้งทีมตามสี* = Sentai · *โตจากทรัพยากร* = Human
- ทุกเผ่าควรมี **1 แผนหลัก** และ **1 แผนรอง** เท่านั้น ถ้าการ์ดไม่เข้าทั้ง 2 แผน ให้ทำเป็นการ์ดไม่มีเผ่า (Neutral)

## 2. รายละเอียดแต่ละเผ่า

### 2.1 Beast — ฝูงที่โตตอนลงสนาม
- **แนว**: ลงตัวเล็กเยอะๆ ทุกตัวที่ลงสนามได้พลังจากหัวฝูง
- **เครื่องมือ**: `ON_PLAY` (Deploy), `ALLY_SUMMONED` + เป้า `SUMMONED`, `SUMMON` token, บัฟ `ALL_FRIENDLY` กรองเผ่า Beast, `ECHO` (Deploy ทำงาน 2 ครั้ง)
- **แผนรอง**: Last Stand เรียกลูก (ตายแล้วยังเหลือตัวบนบอร์ด)
- **บทบาทตาม Rank**
  - R1–2: ตัวเล็กที่ Deploy เรียก token / บัฟตัวเอง
  - R3–4: "หัวฝูง" — เมื่อเรียกยูนิตอื่นเข้าสนาม: ให้ตัวนั้น +X/+X (ถาวรในช่วงซื้อ)
  - R5–6: payoff — บัฟทุก Beast ตามจำนวนตัว, ECHO
- **ห้าม**: ทำลายพวกเอง (เป็นของ Kaiju), Guard หนาๆ
- **ตัวอย่าง**
  - Pack Pup (R1, 1/1): Deploy: เรียก Wolf Cub 1/1
  - Den Mother (R3, 2/4): เมื่อเรียกยูนิตอื่นเข้าสนาม: ให้ตัวที่ถูกเรียก +1/+1
  - Alpha King (R6, 6/6): Deploy: ให้ Beast ทุกตัว +2/+2 · ECHO

### 2.2 Kaiju — ตายแล้วเกิดใหม่แรงขึ้น
- **แนว**: ยิ่งตายยิ่งได้ประโยชน์ ตายครั้งแรกขยายร่าง ตายแล้วทิ้งของไว้
- **เครื่องมือ**: `KYODAIKA` (ตายครั้งแรกฟื้น stat ×2 ไม่มี keyword อื่น), `REVIVE`, `LAST_STAND`, `AVENGE` (N), `DESTROY` / `CONSUME_ALLIES` (ทำลายพวกตัวเองเพื่อพลัง), `TRANSFORM` ตอนตาย
- **แผนรอง**: ช่วงซื้อ ทำลายตัวเองเพื่อแลกค่าพลังถาวร (`CONSUME_ALLIES`, Deploy ทำลายพวกขวาสุด)
- **บทบาทตาม Rank**
  - R1–2: ตัวที่ Last Stand ทิ้งลูก / Revive
  - R3–4: Avenge โตถาวร, Kyodaika
  - R5–6: กินพวก (CONSUME_ALLIES) / ตายแล้วแปลงเป็นร่างยักษ์
- **ห้าม**: บัฟร้าน / Energy (ของ Human), Barrier เยอะ (ทำให้ไม่ตาย ขัดแนว)
- **ตัวอย่าง**
  - Egg Spawn (R1, 1/2): Last Stand: เรียก Kaiju Larva 1/1
  - Rampaging Titan (R4, 4/5): Kyodaika · Avenge (2): ให้ตัวนี้ +1/+1 ถาวร
  - Devourer (R6, 4/4): Deploy: ทำลายยูนิตอื่นของเราทั้งหมด แล้วให้ตัวนี้ได้ ATK/HP รวม

### 2.3 Mecha — รวมร่างแล้วอัปเกรด
- **แนว**: เก็บชิ้นส่วน Gattai วางติดกัน รวมเป็นร่างใหญ่ แล้วร่างนั้นอัปเกรดได้อีก
- **เครื่องมือ**: `GATTAI` (ชิ้นที่ติดกันรวมกันตอนเริ่มสู้), Gattai core (`gattaiInto` + ปุ่ม Combine ถาวร), `ULTIMATE_FORM` / `TRANSFORM` เพื่ออัปเกรดร่างรวม, `SUPER_GATTAI`, Giant Slot (`GIANT_SLOT` เป็นเป้าบัฟ)
- **แผนรอง**: บัฟหุ่นยักษ์ใน Giant Slot (ใช้ร่วมกับ Sentai)
- **บทบาทตาม Rank**
  - R1–3: ชิ้นส่วน Gattai ค่าพลังต่ำ แต่รวมแล้วคุ้ม
  - R3–4: Gattai core (หัวกลุ่ม) ชี้ร่างรวม
  - R5–6: ตัวอัปเกรดร่างรวม (Gear / Deploy เปลี่ยนร่าง), บัฟ Giant
- **กติกาสมดุล**: ร่างรวม ≈ ผลรวมค่าพลังชิ้นส่วน × 1.3–1.5 + keyword 1–2 อย่าง (ได้ช่องบอร์ดคืนคือรางวัลหลัก)
- **ห้าม**: ชิ้นส่วนที่ใช้เดี่ยวๆ ก็แรง (ทำให้ไม่ต้องรวม)

### 2.4 Rider — ปั้นตัวเดียว
- **แนว**: เลือก Rider 1 ตัว ใส่ Gear และรอแปลงร่าง ไปจนถึงร่าง Final Form
- **เครื่องมือ**: `henshin` (N เทิร์น → ร่างใหม่ บัฟติดไป), `HENSHIN` trigger (ใส่ที่ร่างก่อนแปลง), `ultimateInto` + Gear `ULTIMATE_FORM`, Rider Gauge (ได้แต้มเมื่อ Henshin), Gear เป้า `CHOSEN_FRIENDLY` + ตัวกรองการ์ด, `TRANSFORM` (Capsem เปลี่ยนฟอร์ม), `RIDER_KICK`, `BUFF_GEAR`
- **แผนรอง**: Gear เศรษฐกิจ (ได้ Gear สุ่ม, Gear แรงขึ้น) · **ไรเดอร์ฝ่ายร้าย**: ทำให้ศัตรูอ่อนแอก่อนสู้ (−ATK), ทำลายศัตรูตัวสำคัญ
- **บทบาทตาม Rank**
  - R1–2: Rider ร่างแรก (Henshin 2 เทิร์น) / ตัวช่วยให้ Gear
  - R3–4: Rider รอง, ตัวที่บัฟเฉพาะการ์ดชื่อ (`cards` filter / `HAS_CARD`)
  - R5–6: Rider ที่มีร่าง Final Form ในตัว, ตัวที่ทำให้ Gear แรงขึ้น
- **กติกาสมดุล**: ร่าง Henshin ≈ ค่าพลัง Rank+2 ของร่างก่อน · ร่าง Final Form ≈ R6 สูงสุด + keyword 2 อย่าง · Gear ที่บัฟตัวเดียวคุ้มกว่า Gear บัฟหมู่ราว 2 เท่า
- **ห้าม**: บัฟทั้งทีม (เป็นของ Sentai/Beast), ให้ Energy ต่อเทิร์นถาวรสูง (ระวังการ์ดแบบ Nox +2 Energy ทุกเทิร์น)

### 2.5 Sentai — ทีมหลายสีกับหุ่นยักษ์
- **แนว**: เก็บ Sentai สีไม่ซ้ำให้ครบ เกิด Roll Call เติม Mecha Gauge แล้วเรียก Giant Robo
- **เครื่องมือ**: `colors` (RED, BLUE, YELLOW, GREEN, PINK, BLACK, WHITE, PURPLE, SILVER, GOLD, ORANGE · EXTRA = นับเป็นสีที่ขาดได้ 1 สี), เงื่อนไข `TEAM_UP_COLORS_GTE`, Roll Call (ครบ `rollCallColors` = 3 สี: Sentai +1/+1 ในการสู้และ Gauge +1), `DISCOVER_GIANT`, `GIANT_SLOT`, `FINAL_BLOW`
- **แผนรอง**: บัฟ Sentai ทุกตัวตามจำนวนสี
- **บทบาทตาม Rank**
  - R1–2: สีหลักตัวละ 1 สี ค่าพลังกลาง
  - R3–4: Team-Up (3): บัฟทีม / ตัว EXTRA (นับทุกสี)
  - R5–6: ตัวที่เติม Gauge / บัฟ Giant Robo
- **กติกาสมดุล**: ให้สีครบ 5 สีได้ใน Rank 1–3 ในเกมเดียวกัน (ไม่งั้น Roll Call ไม่เกิด) · EXTRA มีน้อย (1–2 ใบ)
- **ห้าม**: ตัวเดี่ยวที่แรงเกินโดยไม่ต้องมีทีม

### 2.6 Human — เศรษฐกิจ
- **แนว**: เทิร์นต้นๆ เก็บทรัพยากร (Energy, การ์ด, Gear) แล้วไปแรงด้วยการ์ดเผ่าอื่นหรือ Human R5–6
- **เครื่องมือ**: `GAIN_ENERGY`, `BUFF_SHOP` (ยูนิตในร้านแรงขึ้นจนจบเกม), `RANDOM_CARD` (Gear/ยูนิตสุ่ม), `DISCOVER_UNIT`, `ADD_TO_HAND`, `ON_SELL` (ขายแล้วได้ของ), `ON_TURN_START`, `MODIFY_RULE` (เช่น ขนาดมือ), เงื่อนไข `ENERGY_GTE`
- **แผนรอง**: Gear support (ให้ Gear, `BUFF_GEAR`) → เล่นคู่ Rider ได้ดี
- **บทบาทตาม Rank**
  - R1–2: ตัวเล็ก ค่าพลังต่ำกว่าเกณฑ์ 1 แต้ม แต่ให้ Energy / การ์ด
  - R3–4: บัฟร้าน, Discover, ขายแล้วได้ของ
  - R5–6: payoff — ค่าพลังตามจำนวน Energy ที่มี / การ์ดในมือ
- **กติกาสมดุล**: 1 Energy ≈ 1 แต้มค่าพลัง (ATK+HP) ของตัวมันเอง · Energy ต่อเทิร์นถาวร ≥ 2 อันตราย ต้องใส่ limit
- **ห้าม**: ค่าพลังสูงกว่าเกณฑ์ (ไม่งั้นได้ทั้งของและพลัง)

### 2.7 Shonen — ยิ่งโดนยิ่งแกร่ง
- **แนว**: ตัวเอกรับดาเมจแล้วโตถาวร เพื่อนตายแล้วปลุกพลัง และมีท่าไม้ตายที่ใช้ได้ครั้งเดียว
- **เครื่องมือ**: `AFTER_DAMAGED` (+ถาวร), `AVENGE`, `ON_ATTACK`, `RAPID`, `RIDER_KICK` (ตีแรก ×2), `BARRIER` (รอดตีแรก), `limit` 1 ต่อเกม (ท่าไม้ตาย), `BUFF` แบบ `fromSelf` (ส่งพลังให้เพื่อน)
- **แผนรอง**: ทีมเพื่อน — เมื่อเพื่อนตายส่งพลังให้ตัวเอก (Last Stand: ให้พวกเอง +X ถาวร)
- **บทบาทตาม Rank**
  - R1–2: ตัว HP สูง ATK ต่ำ ที่โตเมื่อโดนตี
  - R3–4: Avenge / ส่งพลังให้ตัวเอก
  - R5–6: ตัวเอกร่างตื่น (Rapid + Rider Kick) / ท่าไม้ตาย limit 1 ต่อเกม
- **กติกาสมดุล**: โตจากการสู้ ≤ +2 ต่อครั้ง และไม่เกิน 3 ครั้งต่อการสู้ (ใช้ limit) เพราะถาวรสะสมทุกเทิร์น
- **ห้าม**: Revive / Kyodaika (เป็นของ Kaiju)

## 3. ค่าพลังมาตรฐานต่อ Rank

ค่าเฉลี่ยจากชุด prototype (ยูนิตที่ขายในร้าน) ใช้เป็นจุดเริ่ม

| Rank | ATK/HP เฉลี่ย | รวมเฉลี่ย | ช่วงที่มี | ตัวเปล่า (ไม่มีความสามารถ) แนะนำ |
|---|---|---|---|---|
| 1 | 1.5 / 2.1 | 3.7 | 2–5 | 2/2 – 2/3 |
| 2 | 2.6 / 3.3 | 5.8 | 4–7 | 3/4 |
| 3 | 3.4 / 4.3 | 7.7 | 5–11 | 4/5 |
| 4 | 4.5 / 5.3 | 9.8 | 7–13 | 5/5 – 5/6 |
| 5 | 6.4 / 7.8 | 14.2 | 12–18 | 8/8 |
| 6 | 9.4 / 10.4 | 19.9 | 16–26 | 10/10 |

**ราคาความสามารถ** (หักจากค่าพลังรวมของตัวเปล่า)

| ความสามารถ | ราคาประมาณ |
|---|---|
| Guard | 1 |
| Barrier | 2 (R1–2) / 3 (R4+) |
| Rapid | ≈ ATK ของตัวมัน |
| Lethal | 3 (คู่กับ ATK ต่ำ) |
| Revive / Kyodaika | 3–4 |
| Rider Kick | ≈ ATK ÷ 2 |
| บัฟเฉพาะการสู้ +X/+X 1 ตัว | X |
| บัฟ**ถาวร** | ×2 ของบัฟเฉพาะการสู้ |
| บัฟทุกตัว | × จำนวนตัวที่คาดว่าจะโดน (ปกติ 3–4) |
| เรียก token 1/1 | 2 |
| +1 Energy (ครั้งเดียว) | 1 |
| ทำงานทุกเทิร์น / ทุกครั้งที่ ... | ×2–3 ของครั้งเดียว ควรมี limit |

กติกา: **ค่าพลังรวม + ราคาความสามารถ ≈ ค่ารวมเฉลี่ยของ Rank นั้น ±1** · การ์ดที่ต้องมีเงื่อนไข (`HAS_CARD`, Team-Up, จำนวนเผ่า) ลดราคาได้ 30–50%

## 4. จำนวนการ์ดต่อเผ่า

เกมสุ่ม 5 เผ่าต่อล็อบบี้ แต่ละเผ่าควรมีการ์ดในร้านพอให้มีแผนครบทุกช่วง

| Rank | ต่อเผ่า (ขั้นต่ำ) | หมายเหตุ |
|---|---|---|
| 1 | 3 | ตัวเริ่มแผน |
| 2 | 3 | |
| 3 | 3 | ตัวเปิดแผนหลัก (หัวฝูง, core, Team-Up) |
| 4 | 2 | |
| 5 | 2 | payoff |
| 6 | 1–2 | capstone |
| **รวม** | **14–15** | + token / ร่างแปลงตามต้องการ (ไม่นับ) |

- Gear: 2–4 ใบต่อเผ่าที่ใช้ Gear (Rider, Human) เผ่าอื่น 0–2
- การ์ด Neutral (ไม่มีเผ่า, มีทุกเกม): 1–2 ใบต่อ Rank
- ร่างแปลงและ token ตั้ง `token: true` (ไม่ขายในร้าน ขึ้นในหนังสือแท็บ "ร่างแปลง & พิเศษ")

## 5. ขั้นตอนปรับสมดุล

1. **ทำการ์ดครบ 1 เผ่าก่อน** (14–15 ใบ) แล้ว Save draft
2. **Simulate** (Admin → Simulate, 100–300 เกม, target draft): ดูตาราง Factions และ Cards
3. **เกณฑ์**
   - อันดับเฉลี่ยของแต่ละเผ่าอยู่ที่ **4.0–5.0** (8 คน ค่ากลาง = 4.5)
   - การ์ดที่ถูกใช้ ≥ 5 ครั้ง: อันดับเฉลี่ย **≤ 3.8 = แรงเกิน** (แถวเขียว), **≥ 5.2 = อ่อนเกิน** (แถวแดง)
   - การ์ดในรายการ "neverUsed" = bot ไม่ซื้อ / ไม่มีในร้าน → ตรวจ rank และเผ่า
4. **ปรับทีละน้อย**: ค่าพลัง ±1 หรือเปลี่ยนจำนวนครั้ง (limit) ก่อน ค่อยเปลี่ยนความสามารถ
5. หลัง Publish ดู **Stats** (เกมจริง ติ๊ก humans only ถ้ามีผู้เล่นพอ) เทียบกับ Simulate
6. bot เล่นไม่เก่งเท่าคน: แผนที่ต้องจัดลำดับบอร์ด (Mecha Gattai, Sentai สี) bot จะเล่นได้แย่กว่าจริง ให้ดู Stats ของเกมคนเล่นประกอบ
